# いっぷく 店舗管理システム v1

AirレジAPI仕様待ちの間に使えるフロントエンド試作です。

## 入っている機能
- 14席の座席マップ（C01-C06 / T1 4席 / T2 2席 / T3 2席）
- 席をタップして注文内容・状態確認
- 注文一覧 / 受付→準備中→提供済→会計済
- モバイルオーダー画面（座席URL対応）
- Airレジ商品別売上CSVを読み込んだ売上・粗利分析（端末内に保存）
- Airレジ商品別売上CSVの手動読込
- 在庫 / 発注メモ
- 取り置き管理
- 座席別注文URL表示

## 注意
このv1はブラウザの localStorage を使う試作です。
別端末間で注文を共有するにはCloudflare D1/Workers等のバックエンド接続が必要です。
AirレジAPI仕様が届き次第、売上データの自動取得部分を追加できます。

## 初回の売上データ設定
「分析」→「CSVを読み込む」からAirレジの商品別売上CSVを選択してください。読み込んだデータは同じ端末のブラウザに保存されます。
